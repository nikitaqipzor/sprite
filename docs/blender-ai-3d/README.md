# AI + Blender: создание 3D-моделей через MCP

Исследование от **07.09.2026**. Собрано тремя параллельными агентами: MCP-инфраструктура, источники бесплатных ассетов, сравнение LLM.

> **Статус: незавершено.** Задача была прервана на этапе оформления. Ниже — выводы
> из исследования; разборы по MCP-серверам, базам ассетов и роутингу моделей
> ещё не выписаны в отдельные файлы.

## Пять выводов, ради которых всё это писалось

1. **Есть официальный MCP-сервер от Blender Foundation** — `projects.blender.org/lab/blender_mcp`, Blender 5.1+, ставится через Extensions. Anthropic анонсировала его как коннектор 28.04.2026. Community-сервер `ahujasid/blender-mcp` (27.3k звёзд) не умер, но это **два разных протокола на одном порту 9876** — вместе не работают.

2. **Правильный пайплайн — не «нарисуй мне модель», а «найди готовую и собери сцену».** Сам blender-mcp в своём промпте `asset_creation_strategy()` ставит скриптинг на **последнее** место: сначала Poly Haven / Sketchfab / Poly Pizza, потом text-to-3D генерация, и только если ничего не нашлось — bpy-код. LLM тут арт-директор, а не моделлер.

3. **Узкое место — геометрия, а не код.** P3D-Bench: ~0.80 семантического соответствия против ~0.35 геометрического. Модель напишет исполняемый скрипт, который построит правильную по смыслу и неправильную по размерам вещь. Нужен слой численной верификации между генерацией и приёмкой.

4. **Пространственное мышление не покупается более дорогой моделью.** SCBench: лучшие модели 57.6%. Внешний scaffold даёт Claude +17.7% на VSI-Bench — больше, чем разрыв между поколениями моделей. Кватернионы и bbox-коллизии отдавайте в детерминированный Python, не в LLM.

5. **Дефолт по моделям: Claude Opus 5 на весь цикл.** Понижайте `effort`, а не переключайте модель. Вторую модель добавляйте, только когда замерили выигрыш на своей задаче.

## Достоверность

Egress-прокси песочницы заблокировал `arxiv.org`, `polyhaven.com`, `sketchfab.com`, `projects.blender.org`, `www.blender.org`, вендорские доки и большинство агрегаторов бенчмарков. Поэтому:

- Данные по `ahujasid/blender-mcp` — **надёжные**, получены разбором исходников (`server.py` 1823 строки распарсен по AST, `addon.py`, `telemetry.py`, PyPI JSON).
- Цены и API Anthropic — **надёжные**, из официального кэша.
- Точный список инструментов **официального** Blender Lab MCP — **не получен**, домен заблокирован. Не выдумывали.
- Бенчмарки моделей — **вторичные источники**, помечены в 03-model-routing.md. Ни один 3D-бенчмарк не тестировал модели сентября 2026.
